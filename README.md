# PiStationPS4

Projeto experimental de compatibilidade com o sistema original do PlayStation 4,
baseado no [shadPS4](https://github.com/shadps4-emu/shadPS4).

Estado atual: preparação do ambiente de desenvolvimento. Não há suporte validado
ao dashboard do firmware 9.00 nem implementação de `Firmware900Manager`.

O repositório conectado começou somente com este README; ainda não contém o
código nem o histórico do emulador. Os scripts da Etapa 1 preparam uma cópia
local separada, fixada em uma revisão oficial, sem importar código para a branch
principal. Antes da Etapa 2, conecte um fork real do shadPS4.

Consulte [o relatório e as instruções do ambiente](docs/cloud-setup.md).

O shadPS4 é desenvolvido pelo shadPS4 Emulator Project e seus
[contribuidores](https://github.com/shadps4-emu/shadPS4/graphs/contributors).
Os créditos, cabeçalhos e licenças originais devem ser preservados.
Os scripts deste repositório usam GPL-2.0-or-later; veja [LICENSE](LICENSE).
Nenhum firmware, chave ou arquivo proprietário da Sony faz parte desta preparação.
